# D1 – Turrutebasen in Oslo/Bærum, measured (round 2, lead 1)

Accessed 2026-10-29. Publisher of all data: Kartverket (via Geonorge). Measurements come from our own parsing of the downloaded GML files. Python scripts: stats.py, extra.py and enum.py in the session scratchpad.

## Bottom line
- **Access is easy.** The Geonorge download API returned Oslo and Bærum GML files immediately, with no login and no email. A WFS also works.
- **Difficulty grading (gradering) is sparse in Oslo.** Only 11.7% of Oslo foot-route segments have a G/B/R/S grade. No segment is graded R or S. The main DNT routes in Nordmarka and Østmarka are mostly ungraded. Graded routes are mostly urban riverside walks ("-langs").
- **Waymarking (merking) is close to universal.** 97% of segments in Oslo and 100% in Bærum have merking=JA, so the field does not help tell routes apart.
- **Geometry is stored per segment, not per route.** One segment can belong to 1–6 routes. A "hike" has to be built by grouping segments on rutenummer/rutenavn, and some "routes" are whole networks (for example "Blåmerket sti Nordmarka", 91 km).
- **The fields are not quite what the brief assumed.** `rutetype` is a ski-trail importance code (1/2/3), not a hiking type. `underlagstype` exists in the schema but has 0 occurrences in the Oslo and Bærum foot routes. The useful extra fields are `ruteFølger` (what the path runs on, e.g. ST = trail, BV = road), `spesialFotrutetype`, `tilpasning` and `rutebetydning`.
- **Verdict:** Turrutebasen is good as a geometry and name backbone for Oslomarka. It is not sufficient on its own to pick out "beginner" routes. Difficulty would have to be derived, for example from length, `ruteFølger` and elevation, or taken from another source.

## Access steps that worked (reproducible)
1. `GET https://nedlasting.geonorge.no/api/codelists/area/d1422d17-6d95-4ef1-96ab-8af31744dd63` lists the valid areas and the format/projection pairs for each.
2. `POST https://nedlasting.geonorge.no/api/order` with header `Content-Type: application/json` and this body:
   `{"email":"","orderLines":[{"metadataUuid":"d1422d17-6d95-4ef1-96ab-8af31744dd63","areas":[{"code":"0301","name":"Oslo","type":"kommune"},{"code":"3201","name":"Bærum","type":"kommune"}],"formats":[{"name":"GML"}],"projections":[{"code":"25833","name":"EUREF89 UTM sone 33, 2d","codespace":"http://www.opengis.net/def/crs/EPSG/0/25833"}]}]}`
   The response includes `files[].downloadUrl` with status ReadyForDownload. Each download is a zip of about 0.5–0.8 MB.
   - To get WGS84, use format name `"GPX "`. It has a **trailing space** in the codelist, and it is the only format offered in 4326. We did not test it.
3. `curl -L <downloadUrl>`, unzip, then parse the GML. GDAL/ogr2ogr is not installed on this machine. We used a stdlib Python ElementTree script.
4. Alternative: WFS GetFeature, e.g. `https://wfs.geonorge.no/skwms1/wfs.turogfriluftsruter?service=WFS&version=2.0.0&request=GetFeature&typeNames=app:Fotrute&srsName=urn:ogc:def:crs:EPSG::4326&bbox=59.95,10.6,60.05,10.8,urn:ogc:def:crs:EPSG::4326&count=N`

## Leads worth chasing
- **Deriving "beginner" without gradering:** combine route length (from the assembled segments), `ruteFølger` (BV/SB/GS/TV = road or gravel, which is easier) and DTM elevation gain (Kartverket height API). Test this on the 137 named Oslo routes.
- **Assembling routes:** group segments on rutenummer, then stitch them into lines (linemerge). Check whether "osl##" DNT routes named "Ukjent" can be named from their endpoints (RuteInfoPunkt, stedsnavn) or from DNT/UT.no.
- **Better grading sources:** UT.no / DNT tour descriptions, and Oslo kommune (Bymiljøetaten) marka maps.
- **Akershus fylke (32)** covers the rest of Oslomarka (Nittedal, Lørenskog, Enebakk, Nordre Follo, Lunner). It can be ordered the same way.
- Open the 20171210 PDF to see what "I" and "S" mean in the grading. Merkehåndboka (merkehandboka.no) defines the grading criteria.
- Confirm the exact licence name. The metadata shows "Lisens" / "Åpne data"; CC BY 4.0 is our belief and is unverified.

## Looked for but could not find
- **GML in EPSG:4326.** It is not offered: the order silently returned no files.
- **`underlagstype` values in Oslo/Bærum:** 0 occurrences.
- **A newer product specification than 20171210:** none listed in the register.
- **English or Norwegian meanings for gradering S and I in the XSD:** only "Se Merkehåndboka". We believe I = ungraded ("ikke gradert") and S = very strenuous (black), but this is unverified.
- **The WFS feature type list:** our grep of GetCapabilities did not extract the names. `app:Fotrute` works.
- **The `nasjonal-database...Versjon 2.5.1` spec page:** returns 404 (it is a superseded version).
